HOW IT WORKS

From raw log to a checked answer. Three steps.

01

Paste your error log

Drop in a raw SAP error log, a short stack trace, or just describe what you’re seeing — no need to know the T-code or category up front.

SYSTEM_NO_ROLL: TSV_TNEW_PAGE_ALLOC_FAILED
Program SAPLSMTR_NAVIGATION, work process 07
02

The agent searches your runbooks

A bounded tool-calling loop searches the actual runbook corpus and looks up transaction codes — it never answers from memory. Every step it takes is traceable, not a black box.

search_runbook→ 4 passages retrieved
lookup_tcode→ ST22, SM04, ST02
03

Get a verified result — or an honest “no match”

Before anything reaches you, every citation is checked against the evidence actually retrieved, and every T-code is checked against the allow-list. You get a category, an ordered list of T-codes, step-by-step checks, and citations that resolve to real runbook text — or, if nothing matches, a plain “nothing relevant” instead of a confident guess.

RUNBOOK COVERAGE

What BasisMedic can — and cannot — answer

8 incident categories · 16 runbooks · each one verified against real evidence

The runbook corpus is hand-written, covering eight SAP Basis incident categories with two runbooks each. Every match tells you exactly which symptom it was written for, which transaction codes to open in order, and who to escalate to if the fix is outside a Basis admin’s hands. Anything outside this list is correctly refused as out of scope — never guessed.

WHY TRUST IT

Why trust it

A triage assistant that’s confidently wrong is worse than one that says “I don’t know.” Every number on this page is measured against named baselines, and every answer you see has already passed a code-level check — not just a model’s word for it.

EVALUATION-FIRST
bm25densehybrid
bm25 · dense · hybrid

Retrieval isn’t picked by vibes. Each strategy is benchmarked on a held-out test set against named baselines before it ships, and the same evaluation runs again for the full agent end-to-end.

GROUNDED ANSWERS ONLY
0 fabricated

Every citation is checked against the evidence actually retrieved that request. One that doesn’t match gets dropped before it ever reaches you — it never makes it into the answer.

VERIFIED, NOT TRUSTED

Never trusted from the model. T-codes and citations pass a code check against real runbook text before they appear. If nothing relevant is found, the system — not the model — forces an honest “out of scope” instead of a guess.
